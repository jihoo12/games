# 작은 놀이터

브라우저에서 바로 즐기는 **게임 10개 + 도구 10개**. 한국어 UI, 모바일 레이아웃, 검색과 분류를 제공합니다. 프레임워크, 외부 폰트, 런타임 패키지, 서버 API 없이 동작하는 정적 사이트입니다.

## 실행

```sh
python3 -m http.server 8000
# http://localhost:8000
```

또는 `npm start` (Python 3 필요). ES 모듈을 사용하므로 파일을 직접 열기보다 로컬 HTTP 서버로 실행하세요. `main` 브랜치에 푸시하면 기존 GitHub Pages 워크플로가 사이트를 배포합니다.

## 게임

| 게임        | 기능                                          |
| ----------- | --------------------------------------------- |
| 핑퐁        | 기존 게임, 컴퓨터 상대 7점 승부               |
| 스네이크    | 기존 게임, 방향키·터치 조작                   |
| 2048        | 방향키·스와이프·화면 버튼, 최고 점수 저장     |
| 지뢰찾기    | 8×8 / 지뢰 10개, 첫 칸과 이웃 안전, 깃발 모드 |
| 메모리 카드 | 그림 8쌍, 시도 횟수                           |
| 틱택토      | 미니맥스 컴퓨터 대전 / 로컬 2인 모드          |
| 불 끄기     | 풀 수 있는 5×5 퍼즐                           |
| 반응속도    | 무작위 대기, 조기 클릭 감지, 평균·최고 기록   |
| 숫자 맞히기 | 1~100, 7번 기회, UP/DOWN 힌트                 |
| 가위바위보  | 컴퓨터 대전, 승무패 집계                      |

## 도구

계산기(입력 순서대로 연산), 뽀모도로(집중·휴식·사용자 지정), 스톱워치(랩), 단위 변환(길이·무게·온도·넓이), 글자 수(유니코드·UTF-8), 비밀번호 생성(Web Crypto), 랜덤 추첨(주사위·정수·중복 없는 목록), 색상(HEX·RGB), 날짜 차이/날짜 더하기, JSON 정리·압축·검증.

입력값은 브라우저에서 처리하고 전송하지 않습니다. 2048과 기존 스네이크의 최고 점수만 로컬 저장소에 보관합니다. 클립보드는 HTTPS 또는 localhost에서 사용할 수 있습니다. 타이머는 탭을 열어 두어야 하며 시스템 절전이나 브라우저 정책에 따라 알림이 지연될 수 있습니다. 텍스트와 JSON 결과는 HTML로 해석하지 않습니다.

## 구조와 검증

- `index.html`: 홈 / `?app=2048` 등의 개별 기능 링크
- `assets/app.js`: 카탈로그, 검색, 앱 진입
- `assets/games.js`, `assets/tools.js`: 기능 구현
- `assets/core.js`: 순수 게임 규칙, 변환, 날짜·문자 계산
- `assets/ui.js`, `assets/style.css`: 공통 UI
- `tests/core.test.js`: 주요 규칙과 경계값 회귀 테스트

```sh
npm test
```

Node.js 20 이상 권장. 별도 패키지 설치가 필요하지 않습니다. 기존 `pingpong.html`, `snakegame.html` 주소도 그대로 사용할 수 있습니다.
